项目结构
dfir-trainer/
├── 启动特训.bat      ← 双击即启动（仅本机访问）
├── server.py         ← 本地临时服务（127.0.0.1:8899）
├── app/              ← 前端界面（可自行美化魔改）
└── data/             ← 题库与命令库（纯 JSON，可直接编辑）
    ├── commands_linux.json     Linux 应急命令手册
    ├── commands_windows.json   Windows 应急命令手册
    ├── mcq.json                选择题
    ├── fill.json               填空题
    └── scenarios.json          实操场景案例
如何自定义 / 升级题库
  • 用任意编辑器打开 data/*.json，按现有字段格式新增题目/命令/场景，保存后刷新页面即生效。
  • 选择题字段：id, os, category, difficulty, question, options[4], answer(0-3), explanation
  • 填空题字段：id, os, category, question(用 ____ 表示空), answers[等价写法数组], explanation
  • 场景字段：id, title, os, category, difficulty, background, steps[{prompt, commands, simulated_output, hint, explanation}], summary
  • 学习进度与打卡记录保存在浏览器 localStorage（仅本机），换浏览器进度不共享。
